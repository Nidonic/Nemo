A personal agent that does, not just answers.

Nemo is an open-source agent for every device you own. It works through shells, files, the web, MCP servers and the screen itself. It asks before anything you can't undo, and it remembers you in files you can read.

What it does

One agent. Your tools, your devices, your rules.

Nemo runs on your machine and talks to the model you choose: Anthropic, OpenAI, DeepSeek, Gemini, Ollama or any OpenAI-compatible endpoint.

01 · Hands

It does the work

A ladder of action: CLI, MCP and APIs first, then direct HTTP, then a browser. When nothing else works, it uses the screen, with a STOP button always in reach.

02 · Sentinel

It asks first

Every tool call is rated SAFE, MODERATE or SENSITIVE. Destructive commands, payments and sends always ask, and once private data has been read, nothing leaves for an unknown host without your OK.

03 · Devices

It reaches your devices

Type @pc tidy my Downloads on your phone. Your PC does the work, and its approval questions come back to the device in your hand.

04 · Memory

It remembers, in plain files

SOUL.md, USER.md and GLOBAL.md, plus facts you can search. A nightly "dream" tidies them up, and every change can be rolled back.

The agent loop
Think→Gate→Execute→Observe↺

One turn at a time per conversation. Messages sent mid-run join the next step, stuck loops stop themselves, and secrets stay in an encrypted vault, never in config.

From source Any OS

Run the daemon and web console anywhere Python 3.11+ runs: Windows, macOS or Linux.

Quick start guide 
# from source
$ git clone https://github.com/Nidonic/Nemo.git && cd Nemo
$ pip install -e ".[all]"
$ nemo                # daemon + console on http://127.0.0.1:7860

The Windows installer isn't code-signed yet, so SmartScreen may warn on first run: click More info → Run anyway.
